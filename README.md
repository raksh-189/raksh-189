## 1. IntentEdge — Investor Intent Intelligence Engine

### 🏆 Fidelity Investments India Hackathon 2026 — Finalist

**IntentEdge** is a behavioral intelligence platform designed to detect investor intent and identify potential conversion opportunities by analyzing how users interact with a financial platform.

Instead of relying only on explicit user actions, the system uses behavioral signals to understand when an investor is showing interest, hesitation, or potential drop-off.

### 🔍 Key Features

* 📊 **Behavioral Tracking** — captures meaningful investor interactions
* 🧠 **Behavior Score** — evaluates behavioral signals to estimate investor intent
* 🎯 **Intent Detection** — identifies users demonstrating potential investment intent
* 💡 **Conversion Identification** — converts behavioral intent into actionable conversion opportunities
* 📈 **Investor Intelligence** — helps understand user behavior throughout the journey
* 🔐 Backend-driven application architecture with persistent data storage

## 2. FinSight DataHub — Financial Data Ingestion & Analytics Platform

**FinSight DataHub** is a full-stack financial data ingestion and analytics platform that processes market data from CSV files, stores validated information in a database, and presents meaningful market insights through a web application.

The system follows an **ETL (Extract, Transform, Load) pipeline** to move raw financial data into a structured format that can be analyzed and displayed.

### 🔍 Key Features

* 📂 **CSV Data Ingestion** — accepts financial data from CSV files
* 🔄 **ETL Pipeline** — extracts, transforms, validates, and loads financial data
* 🗄️ **Database Persistence** — stores processed market data in a structured database
* 📈 **Market Analysis** — provides financial insights through the application
* 🟢 **Top Gainers** — identifies stocks with strong positive movement
* 🔴 **Top Losers** — identifies stocks with negative movement
* 📊 **Data-driven Dashboard** — presents processed information in an accessible format
* 🧩 **Strategy Pattern** — separates processing strategies to keep the system extensible

### 👨‍💻 My Contribution

I designed and developed the **entire full-stack application**.

My work included:

* Backend architecture

* ETL pipeline implementation
* Data validation and transformation
